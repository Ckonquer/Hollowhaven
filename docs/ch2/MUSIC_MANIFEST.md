# Music manifest — Hollowhaven 2.0.0 (cues m01-m27 + layers)

Master prompt §18.4 asks for: source/generator, composition id, duration, playlist/location, import format, peak/loudness and
observed in-game selection. This file collects them from the evidence; it adds no new measurement.

**Listening status: NOBODY HAS LISTENED to any of this music** (neither the 22 new compositions nor their layers, nor the Music
Box, nor any in-game mix). Every "verified" note in the source manifests says "analysis only - not listened" or "NOT VERIFIED by
listening". Loudness, peaks, loop seams, spectrograms and note data were checked by numbers only. Subjective quality, how the
pieces feel in place and whether the transitions sound good are **NOT VERIFIED**.

MusicDirector's decision, not proof that sound came out or that it sounded right. Runs S2-S4 and the S0 `vfix_*` runs started from
diagnostic fixtures; S0 `run1/run2/run11`, all S1 runs and the chain runs started naturally (see `QA_REPORT.md` §9.4). The chain runs
(`qa/tmp/bot/chain/`) ran on a pre-release source snapshot, not on the 2.0.0 exe.
